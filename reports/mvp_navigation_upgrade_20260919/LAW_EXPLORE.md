# State/category navigation and availability

`explore.py` provides `/api/explore` through the parent-owned server integration. It reads existing catalogs without a rebuild and returns jurisdiction, category, source-collection, availability, and date information. The count is a distinct local display-document count plus a separately identified bulk publisher-record count. Source/category/state facets may overlap because a single grouped document can retain several source observations; their counts must not be summed.

Availability uses the displayed preferred record in grouped mode and the individual row in source mode. “Saved text” requires a catalog version explicitly indexed from nonempty text or the compact nonempty-inline flag. “Saved source file” includes the preserved bulk Parquet file and does not imply an official PDF. “Link only” requires a source URL and neither saved text nor a saved file. Unknown availability filters return zero matches.

The metadata query uses the existing indexed `versions(content_id)` relationship. The source importer creates searchable contents only for `content.strip()`. A first implementation reading character counts after large text fields took 23.442 seconds; the indexed-provenance implementation took 2.652 seconds on its first measured call and 0.375 seconds for a cached state request. These runs had different filesystem-cache conditions and are not a controlled speedup benchmark. Bulk facets use the 229 file-metadata rows, not the three-million-row body table. The current frozen bulk snapshot explicitly measures all 2,978,617 rows as nonempty; these text counts depend on that retained measurement.

Snapshot dates, local publication dates, index-build dates, and legal currency stay distinct. `published_at` is supplied only for an explicit focused/bulk publication timestamp; other datasets return null. `indexed_at` carries the separate local index time. A uniform legal “as of” date is not verified, so `source_as_of` is null with a readable explanation. The bulk snapshot's date appears separately. A zero category count describes this saved library only.

Ten tests passed in 15.075 seconds, including direct integration with `server.query_documents`: Pennsylvania/Kentucky rule and statute counts, all availability options, New York's 40,140 bulk statute rows, member deduplication, preferred-record semantics, empty canonical text, and unknown dates/filters. The final narrow timestamp-label correction then passed its targeted regression in 0.051 seconds. `law_explore_verification.json` records hashes and exact evidence. No live source acquisition or main database rebuild was performed.
