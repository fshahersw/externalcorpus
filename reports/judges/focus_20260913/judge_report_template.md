# Judge report — [reported name]

**Identity and scope:** Reported name, publisher profile URL, official identifier if verified, court, jurisdiction, source date and capture date. State whether identity matching and current service are verified. Preserve conflicting source assertions.

**Facts as reported:** Court/department, appointment or election, education, previous work and professional service. Each fact needs a literal source passage or table cell, source URL, saved raw/text path and hash, and a line/section/row locator. Keep county null when the source provides only a combined court/county label.

**Trellis-reported analytics:** Include a metric only when an actual value, unit, population/denominator, time window and filters are present. Attribute it to Trellis. Record absent context or login/subscription placeholders as gaps. Marketing and dashboard links are not metrics.

**Independently calculated statistics:** Separate from publisher analytics. Provide judge identity linkage, decision-level evidence, outcome definitions, observation window, numerator/denominator, deduplication, missingness and sample limitations. If these inputs are absent, report “not computable from the saved evidence”; retain null values.

**Access and evidence gaps:** Profile not captured, missing body, unavailable dashboard, no published denominator, unverified current appointment, unresolved identity, or incomplete jurisdiction coverage. An unobserved metric is not zero.

**Source inventory:** Exact original paths/hashes, source URLs, capture times, stated editions, extraction method and limitation notes. Do not infer judge quality, fairness, likely decisions or national completeness from directory membership or biography.
